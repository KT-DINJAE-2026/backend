# TCD 학습용 승객 명부 (roster_all.parquet) — AI 파트 전달 문서

백엔드 데이터 파이프라인(`data-pipeline/`)이 생성한 학습용 명부의 명세·통계·유의사항입니다.
스펙은 이슈 #1의 `TCD_학습용명부_예시스펙.parquet` 18컬럼을 따릅니다.

## 1. 파일 개요

| 항목 | 값 |
| --- | --- |
| 파일 | `roster_all.parquet` (77MB, zstd 압축) + 일자별 `roster_YYYYMMDD.parquet` 30개 |
| 범위 | 서초구 승·하차 TCD, 2025-04-01 ~ 2025-04-30 (30일, 심야버스는 익일 04시까지 포함) |
| 규모 | **9,549,276행** (승객 1명의 1회 탑승 = 1행), 운행회차 281,993개, 노선 87개 |
| 대상 | 마을버스(105/151, 20석) · 간선버스(115, 25석) · 지선버스(120/121/122, 25석) |
| 레이블 | `is_standing`, `standing_seconds` — 재차인원 복원 + FIFO 좌석배정 시뮬레이션 산출 |

## 2. 실제 예시

### 예시 A — 한 운행회차의 연속 승객 (한산한 밤 시간대)

차량 106048271, 4/16(수) 21:14 시작 회차, 지선버스 노선 100100234. 밤이라 전원 착석.

| board_datetime | board→alight | headway_sec | is_standing | standing_seconds | sample_count |
| --- | --- | --- | --- | --- | --- |
| 21:26:22 | 122000651 → 121000107 | 606 | N | 0 | 80 |
| 21:31:14 | 122000007 → 119000284 | 551 | N | 0 | 47 |
| 21:33:22 | 122000008 → 121000017 | 561 | N | 0 | 85 |
| 21:33:24 | 122000008 → 121000019 | 561 | N | 0 | 96 |
| 21:41:18 | 121000107 → 121001314 | 494 | N | 0 | 90 |

같은 `trip_round_id` 안에서 `board_datetime`이 단조 증가합니다(버스가 노선을 진행하며 순서대로 태그).

### 예시 B — 출근 8시대 입석 사례 (입석시간 스펙트럼)

| 요일·시각 | 유형(좌석) | 날씨 | headway_sec | standing_seconds | 위험도 환산* |
| --- | --- | --- | --- | --- | --- |
| 금 08:15 | 마을(20) | 맑음 | 551 | 50 | 보통 |
| 목 08:43 | 간선(25) | 맑음 | 470 | 162 | 보통 |
| 월 08:07 | 마을(20) | 맑음 | 876 | 253 | 보통 |
| 월 08:01 | 간선(25) | 맑음 | 509 | 498 | 높음 |
| 화 08:12 | 지선(25) | **비** | **897** | **1,023 (17분)** | 높음 |

\* 기획안 기준(입석 5분=300초 경계) 환산. 배차간격이 길고 비가 오면 입석이 길어지는 신호가 원시 데이터에서 그대로 보입니다.

## 3. 주요 통계

- **입석률**: 전체 9.9% (940,920명). 시간대별 피크: **8시 24.6%, 18시 22.3%** (주중 10.9% vs 주말 5.0%)
- **입석시간**(입석자 기준): 중앙값 265초, 평균 344초, 90% 분위 723초. **5분(300초) 초과가 44.4%**
- **버스유형별 입석률**: 마을 13.5% > 간선 9.0% > 지선 8.6%
- **사용자유형별 입석률**: 청소년 13.4% > 어린이 12.7% > 일반인 9.8% > 장애인 7.6% > 경로 6.5% > 국가유공자 5.9%. **경로 입석자의 입석시간 평균 5.6분, 44%가 5분 초과** → 발표용 실증 포인트(기획 Q4)로 활용 가능
- **날씨 분포**: 맑음 57% / 흐림 23% / 비 12% / 구름많음 7% / 눈 0.8%(4/13 이례적 4월 눈) — 날씨 피처 학습에 필요한 분산 확보

## 4. 컬럼별 결측(NULL) 규칙

빈 문자열·센티널 값 없이 **parquet 네이티브 NULL로 통일**했습니다.

| 컬럼 | NULL 수 (비율) | 의미 |
| --- | --- | --- |
| `alight_stop_id` | 170,612 (1.8%) | 하차 미태그 (재차 점유는 회차 종료까지 반영) |
| `headway_sec` | 152,139 (1.6%) | 해당 (노선, 정류장)의 당일 첫차 — 직전 차량이 없음 |
| `usertype_name` | 0 | 코드집 확정(01 일반인 ~ 08 기타) 반영으로 전 코드 매핑 완료 |
| `standing_seconds` | 28 | 입석 상태로 하차 미태그 → 지속시간 확정 불가 |

## 5. 유의사항 (중요)

1. **`trip_round_id`는 "차량ID_회차 첫 승차태그 시각"** — TCD 필드21(운행출발일시)이 일부 차량에서 하루 종일 고정되는 결함이 있어, ROUTESTTN 정류장 순번 역행 감지로 회차를 분리하고 첫 태그시각을 사용합니다. **출발시각이 아니므로 시각 피처로 파생하지 마세요.** (상세: f21 결함 이슈)
2. **`sample_count_route_segment_hour` 집계 기준** — `roster_all.parquet`은 **4월 전체 기준**으로 계산돼 있습니다(일자별 파일은 그날 하루 기준이니 통합본을 쓰세요). 월 기준 (노선, 승하차 OD쌍, 시간대) 조합은 573,956개로, **표본 5건 미만 행이 5.8%, 30건 미만이 36.5%**입니다. 참고로 하차 무관 (노선, 승차 정류장, 시간대) 기준이면 30건 미만이 2.5%로 급감합니다 — `INSUFFICIENT_DATA` 경계값과 "구간" 정의(OD쌍 vs 승차 정류장)를 이 수치 기반으로 함께 정하면 좋겠습니다.
3. **서초구 경계 한계** — 승차·하차 모두 서초구 밖인 승객은 원본에 없어, 경계를 걸치는 노선은 재차인원이 실제보다 소폭 과소 복원됩니다(혼잡 상위 회차 순간 최대 재차 54~71명으로 물리 범위 내 확인). 전 지역 데이터 수급 시 자연 해소됩니다.
4. **좌석수는 유형별 고정값**(마을 20, 간선·지선 25) — 이슈 #2 합의. 1카드=1명 가정이며 필드35(이용자수) 동반탑승 보정은 미적용(파일럿 오차 클 때 도입 예정).
5. `board_datetime`은 문자열이 아닌 **timestamp 타입**입니다. `is_standing`은 스펙 예시대로 "Y"/"N" 문자열 유지.
6. 4/30 심야버스의 자정 넘김 태그 2,753행이 `board_datetime` 5/1 새벽으로 존재합니다(정상).
