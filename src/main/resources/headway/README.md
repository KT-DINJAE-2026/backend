# 서울시 계획 배차간격

`seoul-bus-headway-20260804.csv`는 서울시 버스노선 기본정보 엑셀의 평일·토요일·공휴일
공동배차 시트에서 모델 입력에 필요한 값만 추출한 런타임 자료다.

- 원본: `서울시버스노선기본정보(20260804).xlsx`
- 조회 키: 이용자에게 표시하는 노선번호(`1014`, `103`, `142` 등)
- 출력: 평일·토요일·공휴일 계획 배차간격(초)
- 변환: 원본의 분 단위 값을 60배하고, `0` 또는 빈값은 CSV에서도 빈값으로 저장
- 중복: 동일한 노선번호의 중복 행은 세 시트에서 값이 같은지 확인한 뒤 한 행으로 합침
- 범위: 중복 제거 후 노선번호 723개

일요일은 공휴일 배차간격을 사용하고, 법정공휴일은 요일과 관계없이 공휴일 값을 사용한다. 값이
비어 있거나 노선번호가 매핑되지 않으면 `headway_sec`는 `null`로 모델에 전달한다.

노선번호는 이 파일을 찾는 용도로만 사용한다. PMML의 `route_id`에는 기존 국토부/서울 표준 노선
ID를 그대로 전달하며 `1014` 같은 표시 번호로 교체하지 않는다.

이 자료는 노선·요일 유형별 **계획 평균 배차간격**이다. 학습 Parquet의 `headway_sec`는 승차 태그로
관측한 이전 운행회차와의 시간 차이이므로 정의가 다르다. 현재 값은 운영 입력의 대체값이며, 최종
모델은 운영과 같은 계획 배차간격 정의로 학습 데이터를 다시 생성해 재학습하는 것이 안전하다.

## 사용 중단 결정 (2026-08-24)

AI팀 최종 확인 결과 학습의 `headway_sec`는 교통카드 태그 기반 실측 간격이고, **모델 A(입석
여부)가 이 피처에 gain 기준 약 72% 의존**한다(모델 B는 약 2.3%). 정의·분포가 다른 계획값을
넣는 것보다 학습 때 검증된 결측(결측률 1.03%) 경로가 안전하다는 AI팀 권고에 따라
`app.headway.enabled` 기본값을 끄고 운영에서 `headway_sec`를 결측(NaN)으로 입력한다.

이 CSV와 공급자 코드는 삭제하지 않는다. 운영과 같은 계획 배차간격 정의로 재학습한 모델을
받으면 `HEADWAY_SCHEDULE_ENABLED=true`로 되돌려 재사용한다.
